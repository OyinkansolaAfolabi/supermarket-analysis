# Market Basket Analysis

A Python tool that uses a Graph data structure to find frequently co-purchased items in supermarket transactions.

## Dataset

**File:** `Supermarket_dataset_PAI.csv`  
**Size:** 38,765 transactions, 167 unique items

## How to Run

```bash
# Run the main program
python3 main.py

# Run tests
python3 -m unittest test_main -v
```

## Requirements

- Python 3.7+
- No external libraries required
